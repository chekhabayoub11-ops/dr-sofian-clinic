# Portfolio clinic website

واجهة عربية تجريبية لموقع عيادة أمراض الجهاز الهضمي والمناظير، مع نموذج حجز تفاعلي ولوحة إدارة للعرض التصميمي.

## نسخة العرض

- `APP_MODE` مضبوط على `demo` في `supabase-config.js`.
- نموذج الحجز يعرض بطاقة تجريبية محلية فقط. لا يرسل بيانات النموذج أو الصور أو الأعراض إلى خادم، ولا يحفظها في قاعدة بيانات.
- صفحة `admin.html` للعرض البصري فقط، ولا تقبل تسجيل دخول ولا تعرض سجلات مرضى.
- لا تدخل معلومات شخصية حقيقية. أسماء العيادة والصور والأرقام والنصوص الطبية في التصميم يجب اعتمادها من صاحب العيادة قبل استخدامه كموقع فعلي.

## النشر على GitHub Pages

المستودع يتضمن سير عمل GitHub Actions في `.github/workflows/pages.yml` لنشر الواجهة عند الدفع إلى `main`. فعّل Pages للمستودع واختر **GitHub Actions** كمصدر النشر. صفحة الموقع ستكون متاحة عبر رابط GitHub Pages بعد نجاح أول تشغيل. يمكن فتح `index.html` محلياً أو تقديم مجلد المشروع بخادم ملفات ثابت.

GitHub Pages يستضيف ملفات ثابتة فقط. خدمة FastAPI في `backend/` غير مستخدمة في نسخة البورتفوليو ولا تُنشر أو تُشغّل من هذا الموقع.

## خدمة الفرز (للتطوير المنفصل فقط)

```sh
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

لا تربط هذه الخدمة بمعلومات صحية حقيقية دون مراجعة سريرية وأمنية وخصوصية مستقلة. لا توجد قاعدة بيانات مجهّزة في المستودع. اختبار `backend/load_test.py --supabase` يتطلب تعيين `SUPABASE_URL` و`SUPABASE_ANON_KEY` صراحةً ويكتب حجوزات اصطناعية إلى ذلك المشروع.

## التحقق

```sh
cd backend
pip install -r requirements-dev.txt
python -m pytest -q
```
